# Shubhendu Jena — research portfolio

A dependency-free, responsive portfolio for Shubhendu Jena's 3D computer vision research and engineering work.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

Push the contents of this repository to the `main` branch. GitHub Pages will serve the site at [shubhendu-jena.github.io](https://shubhendu-jena.github.io/).

## Updating content

- Replace `assets/shubhendu-jena-cv.pdf` when the CV changes.
- Publication and experience content lives in `index.html`.
- Theme and responsive layout live in `styles.css`.
- The site is plain HTML and CSS, with no JavaScript dependencies.
